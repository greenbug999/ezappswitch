ezappswitch 1.2.0 — Native radial app launcher for macOS

INSTALL
Open the DMG and drag ezappswitch.app to Applications.
Open ezappswitch, choose Open System Settings, and allow it in
Privacy & Security > Accessibility. If needed, add /Applications/ezappswitch.app.
Choose two pinned apps in Settings.

USE
Hold the left mouse button still for 1 second, point to an app, then release.
Release at the center or an empty slot, move outside, or press Esc to cancel.
Moving before the menu opens preserves normal dragging.

SETTINGS
Default 6 slots, configurable from 2 to 8. Two are pinned; the rest are recent
apps, with pinned duplicates excluded and empty placeholders when needed.
Hold duration: 0.3–5 seconds, default 1 second.
Menu size: 75%–150%, default 100% (the original size).
Reset defaults changes only duration and size, not pins or recent history.
Launch at login is optional. Pause and quit from the menu bar.
Recent history starts when ezappswitch is running and stays on your Mac.

UPGRADING
Quit the older version before replacing the app in Applications.
Existing pins, history, and preferences are preserved. If Accessibility access
stops working, remove the old entry and add /Applications/ezappswitch.app again.

COMPATIBILITY AND SIGNING
macOS 13+. Universal binary for Apple Silicon and Intel.
Runtime-tested on Apple Silicon; Intel hardware has not been tested.
Locally ad-hoc signed, not Apple-notarized. If macOS blocks the app after a
normal open attempt, use its app-specific Open Anyway option in System Settings.
Do not disable Gatekeeper or System Integrity Protection.

Normal clicks are forwarded on mouse-up. Pause ezappswitch in games, drawing apps,
or tools that rely on immediate mouse-down. Lock screens are not supported.
The launcher does not request screen recording access or make network requests.
