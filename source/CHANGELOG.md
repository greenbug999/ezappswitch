# Changelog

## 1.2.0

First public English-language release.

- English application interface, menu-bar actions, setup instructions and screenshots.
- Native frosted-glass radial menu with light and dark appearance support.
- Default six slots, with two manually pinned apps and up to six recent-app slots.
- Configurable hold duration (0.3–5 seconds) and menu size (75%–150%).
- Local persistence, launch at login, and menu-bar pause/quit controls.
- Normal dragging and native settings controls keep their expected behavior.
- Universal macOS app for Apple Silicon and Intel, with local ad-hoc signing.
